# Source manifest for the slim cppup_bootstrap binary.
#
# Consumed by bootstrap.sh AND bootstrap.bat — keeping the source list here
# means the two scripts can't drift apart. Lines starting with '#' are
# comments; blank lines are ignored. Section headers are [bracketed]; every
# non-comment line until the next section is a path (relative to repo root).
#
# Two sections:
#   [config] -> compiled into libcppup_config (the configuration API)
#   [main]   -> compiled and linked against libcppup_config to produce
#               the slim cppup_bootstrap binary.
#
# Paths use forward slashes. Both bash and Windows batch handle them on
# their respective platforms (cmd.exe accepts '/' in g++ args, and MinGW
# tools accept them natively).
